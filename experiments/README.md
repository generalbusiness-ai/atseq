# Retained experiment evidence

The captures in this directory record earlier spike runs. In particular,
`performance.json` and `browser-performance.json` are historical measurements,
not measurements of the current host. See [host performance](../docs/host-performance.md)
for the controlled Adoption F comparison and its raw captures in `adoption-f/`.

Keep the original captures and author bundles intact so their recorded evidence
can be inspected independently of later implementations.
