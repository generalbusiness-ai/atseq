The selected-commit and exact-response helpers are implemented in `src/protocol/native-observer-car.ts`. They give the future native observer a small CAR to admit into its existing verified repository cache. The output contains only the owned selected commit and the complete checked response. It carries bytes, not identity authority or a new capability.

This implements API4 in the independently accepted [P2-D5 note](../experiments/post-spike-evidence/2026-10-02/p2-selected-car-intake/adopted/2026-10-02-atseq-native-proof-extraction-intake.md). `selectNativeObservationCommit(raw)` shares the constructor's parser, one-root/present-commit checks and portable initial budget. It returns a copied root/commit DATA pair. `exactAdmissionCar(raw, requested, selectedCommit)` shares `addExact`'s exact-set predicate, checks all physical blocks before deduplication, and owns the request list, raw response and commit bytes before its first await. Extra blocks, missing blocks and invalid hashes keep their existing distinct refusals. No valid-looking subset is returned.

The maintained CAR writer emits its small header first. The helper then computes the exact serialized size from that header, CID bytes, entry-length varints and raw block bytes before allocating the output or serializing entries. It uses the writer's public API and the installed public varint size function. It sorts only the at-most-65 output blocks. The response may contain at most 64 physical blocks, including duplicates; the selected commit is deduplicated when already requested.

The existing constructor still limits unique **raw** retained bytes to 16 MiB and unique blocks to 50,000. The new helper limits actual **framed** output to 16 MiB. A fixture with raw bytes below that first limit and a CAR one byte above the second is accepted for selection and refused for serialization. Raw input remains bounded at 32 MiB, headers at 16 KiB, header depth at 64 and each block at 1 MiB. No limits, dependencies, profiles, public barrel exports, P1 verifier or observer runtime route changed.
